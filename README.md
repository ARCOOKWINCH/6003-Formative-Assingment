
# COMP6003 Formative Assignment

## About this project

This project is for my COMP6003 formative assignment.

I'll be using Python and Newton's Law of Cooling to model how a server room cools down after its chiller restarts.

The aim is to work out how long it takes for the room to cool below 27°C, so the servers can be safely turned back on.

## Tools used

- Python
- NumPy
- SciPy
- pandas
- Matplotlib
